Mechanical rules

Data and cache behavior

  • Database is authoritative for every write.
  • Components use query option factories, not inline request functions.
  • Forms own local drafts and reset from the saved response.
  • Each domain has one cache update and invalidation helper.
  • Workers Cache only stores authenticated analytics snapshots after auth.
  • Pending orders, inventory, payments, and mutations stay fresh.
  • Transport errors and expected domain errors render differently.

Cutover

Route completion checklist

Check these before the new admin replaces the current one.

  • Replacement deploys to staging only until explicit cutover approval.
  • All V1 routes work at 393x852 with no horizontal scroll.
  • Keyboard traversal and visible focus work.
  • Loading, empty, error, retry, and success states exist.
  • Product and order writes persist after a full reload.
  • No raw enums or library validation strings reach the UI.
  • Analytics ranges produce correct values and cache invalidation works.
  • The real admin completes the main workflows on the iPhone.
  • Old admin routes and unused procedures are removed after cutover.
